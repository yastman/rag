# data/

Fixtures and seed data for local runs and demos.

## `apartments.csv` — demo apartment seed (#3203)

Synthetic, PII-free apartment catalog for the demo Telegram bot.

- **Provenance**: generated by [`scripts/apartments/generate_seed.py`](../scripts/apartments/generate_seed.py)
  (`uv run python scripts/apartments/generate_seed.py`); `--check` verifies the
  tracked file is byte-identical to the generator output.
- **Deterministic**: pure function of RNG seed `3203` and the canonical demo
  domain in [`src/runtime/domain_defaults.py`](../src/runtime/domain_defaults.py)
  (`DEMO_CITIES`, `DEMO_COMPLEX_CITIES`). No real personal data: all complex
  names, sections, numbers, areas, views, and prices are fabricated.
- **Truthful by contract**: every visible demo example maps to real rows. The
  golden demo queries (`GOLDEN_DEMO_QUERIES`) each return at least
  `GOLDEN_QUERY_MIN_RESULTS` (3) listings through the production filter path
  (regex extractor → Qdrant filter), and `NO_RESULT_DEMO_QUERY`
  ("Трёшка в Свети Власе до 60 000€") deliberately returns zero to exercise the
  empty-state recovery copy. Locked by
  [`tests/unit/services/test_demo_seed_truthfulness.py`](../tests/unit/services/test_demo_seed_truthfulness.py).
- **Size**: 300 listings (10 demo complexes × 30) across the three demo cities —
  Солнечный берег, Свети Влас, Элените — covering rooms 1–5, all view options,
  and furnished/promotion flags.

Ingest into a local Qdrant with
`python -m src.ingestion.apartments.runner` (see [`docs/INGESTION.md`](../docs/INGESTION.md)).
